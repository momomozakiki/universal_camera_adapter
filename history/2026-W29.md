- **What:** Rebuilt the single-page example into a 5-tab **camera testing toolkit** (Material 3
  `NavigationBar` + `IndexedStack` shell in `main.dart`), mirroring the tab-shell pattern in

  `ChangeNotifier` owning the **single** `CameraAdapter` + a serialized op-queue — idiom ported

  (JPEG→`image` decode→downsample to 768px→`flutter_zxing`/zxing-cpp `readBarcode`);
  `scanning/frame_scanner.dart` (polls `captureFrame()` ~400 ms with a re-entrancy guard; a
  no-code frame keeps polling, a `StateError`/`TimeoutException` stops the loop + reports inline);
  `tabs/preview_tab.dart`, `tabs/scanner_tab.dart` (shared QR/barcode UI) + thin
  `qr_scanner_tab.dart`/`barcode_scanner_tab.dart` wrappers, `tabs/gallery_tab.dart`,
  `tabs/ptz_tab.dart`, and `widgets/no_camera.dart` (inline Connect placeholder for non-Preview
  tabs). Added `image` + `flutter_zxing` deps to `example/pubspec.yaml`.
- **Why:** User asked for the example to become a testing toolkit — a bottom nav bar of common,
  useful camera-test tools (QR scanner, 1D barcode, capture gallery, PTZ) — each built **on our
  adapter** so the package is exercised across real use cases. Scanners poll `captureFrame()` so
  the `CameraAdapter` stays the only camera seam (no contract change). `flutter_zxing` chosen over
  QR-only `zxing2`/platform-locked ML Kit because it decodes QR **and** 1D on Android + Windows.
  Everything is capability-driven (Android phone is the primary target): zoom/pan/tilt sliders
  disable + tooltip when `capabilities` says unsupported — a phone's PTZ tab reads "not supported"
  by design.
- **Verified:** `flutter analyze --fatal-infos` on `example/` → clean; `flutter build apk --debug`
